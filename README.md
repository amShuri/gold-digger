# GoldDigger

GoldDigger is a small web app that simulates buying gold at a fluctuating price.
Users can enter an investment amount, purchase gold, and have their transaction
recorded.

## Preview

![Performing a transaction](/preview.gif)

## Built with

- HTML
- CSS
- JavaScript
- Node
- Nodemailer & PDFKit

## What I learned

Server-Sent Events: Reading the documentation and exploring different implementations
helped me understand how SSE could be used to handle the app's connection status
and provide live price updates.

Event Emitters: I got to experience firsthand how useful Event Emitters can be.
I used a single Event Emitter to handle both PDF generation and sending purchase
emails.
